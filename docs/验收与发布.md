# 晓球验收与发布

每次发布前运行改动相关的测试、类型检查与三端构建。对数据库和权限的验收使用隔离测试库及虚构数据，检查正式服务当前镜像、迁移和运行配置，建立可恢复的备份。临时产物在 `XQ-work`，旧版独立工程用于回退。

小程序产物须通过登录 PNG 和内联图标资源门槛，核对主包体积与真实微信工具运行。验收状态区分构建、微信模拟器、真机、开发版上传、平台审核及正式上线。用户负责本次提审。

## 0.9.4 开发版

赛中暂存继续作为直播记录。开赛后，授权录入人员可在完赛时直接确认比分，淘汰赛平局须填写双方点球比分。正式赛果立即参与积分和晋级，缺少进球人或分钟的事件留待补录。已确认比分由管理员更正。

球队管理入口移至封面右侧，沿用现有球队权限。返回栏显示球队、球员或用户详情，球员赛程的星期移到日期后。已按确认清理测试队 `QA-TEST-CAPTAIN`、对应成员关系和有效队长权限，保留账号和审计。备份位于 `/opt/xiaoqiu/backups/xq-094-20261117`，API 已更新至 0.9.4。

API 324 项、小程序 303 项测试、相关类型检查和三端构建通过。两组隔离 PostgreSQL 与 HTTP 专项测试通过。旧报告套件有 13 个子用例失败，使用 0.9.3 与 0.9.4 在相同隔离条件下复跑，失败项一致。

独立工程 `XQ-work/releases/0.9.4` 已通过资源检查、微信预览并上传开发版。主包 2,095,881 字节，总包 2,227,341 字节。两行版本说明沿用 0.9.2。真机验收、平台审核和正式上线待完成。

## 0.9.3 开发版

沿用 0.9.2 的发布模式与两行版本说明。独立工程 `XQ-work/releases/0.9.3-r2` 通过资源检查和微信预览，已上传为开发版。主包 2,096,478 字节，全部包合计 2,227,938 字节。真机验收、平台审核和正式上线仍待完成。

待定签位使用通用队徽和「待定」；对阵图日期单行显示，比赛场地移到详情上排，首页动态标题与「换一批」垂直居中。球队详情管理入口随球队权限显示，赛季标题取后台数据。

配套 API 已部署为 `xiaoqiu-api:xq-0.9.3-20261117`。两场新生杯男足半决赛的旧报告在赛后确认，但仍标记为直播比分。保留原报告和比分并追加正式修订后，补齐决赛（物院一队对数院一队）和季军赛（心公联队对人工智能）。备份及晋级预览在 `/opt/xiaoqiu/backups/xq-093-20261117`。历史补位命令先输出预览，写入需提供当次预览哈希；锁定场次或已有签位发生冲突时拒绝写入。

API 324 项、小程序 303 项测试通过，隔离 PostgreSQL 两组真实 HTTP 验收覆盖历史空签位补齐、正式比分自动晋级及 2027 赛季标题。相关类型检查与三端构建通过。
