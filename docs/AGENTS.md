
# AGENTS.md — 晓球微信小程序工程规范

## 1. 工程定位与技术边界

- 本工程为「晓球」微信小程序端（Taro 4 + React 18 + TypeScript Strict），仅面向微信小程序运行时（`weapp`）。
- 禁止引入浏览器 DOM API、`*.h5.*` 多端后缀文件或 Web 端专用依赖。
- 生产环境通过微信云托管（`wx.cloud.callContainer`）与后端通信，本地调试支持通过环境变量切换直连 API。

## 2. 分层与代码组织规范

- 严格遵循 `docs/ARCHITECTURE.md` 定义的单向依赖：`pages` → `components` / `store` → `services` → `types`。
- 网络请求必须收敛在 `src/services/` 内，严禁在页面或组件中直接调用 `Taro.request` 或 `wx.cloud.callContainer`。
- 跨模块引用统一使用 `@/` 路径别名，禁止超过两级的相对路径引用。
- 保持代码库整洁：不保留废弃代码、注释掉的旧逻辑、一次性调试脚本或未引用的静态资源。
- 严控主包体积（< 2MB）：`src/assets/` 仅存放轻量图标，业务大图与默认封面一律通过后端媒体网关加载。

## 3. 视觉与交互工程标准

- 排版与字号须保证移动端高可读性，避免大面积留白配极小文字；交互控件预留充足触控热区。
- 真实队徽与占位队徽保持严格一致的圆形尺寸与透明背景。
- 个人背景与球队背景统一采用 `2.8:1`（`2240×800`）预裁剪比例完整展示，文字叠加层配置半透明浅色底衬。
- 球场阵容组件严格锁定 `105:68` 标准比例，球员节点按归一化坐标渲染在球场边线内。
