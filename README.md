# 晓球 · 校园足球的随身看台

每到比赛日，球场边总是热闹的。有人早早占好位置等主队入场，有人一下课就跑来看最后十分钟，还有人在宿舍里惦记着那场比赛的比分。晓球就是为这些时刻准备的微信小程序。它把校园足球的赛程、比分、球队、球员和大家的故事装进手机里，让每一位关心比赛的同学，打开微信就能走进自己的看台。

无论你是爱看球的观众、场上奔跑的球员，还是带队的队长和教练，都能在晓球找到属于自己的位置。下面就带你慢慢走一圈。

## 初次见面

在微信里打开晓球，首先看到的是登录页。新同学点击“注册”，填写姓名、十位学号和密码，系统会自动和学生名单核对，确认之后就能进入首页。邮箱可以顺手绑定，以后用邮箱验证码登录会更方便。老朋友可以用学号和密码登录，也可以选择邮箱验证码登录。如果一时忘了密码，在“找回密码”里填上姓名和学号，设置一个新密码，很快就能回来。想先随便逛逛的话，登录页的游客入口会带你先看看公开的赛事内容。

第一次进来，不妨按这样的顺序熟悉一下：先在“赛程”里选好自己关心的赛事，点开一场比赛看看；再到底部中间的主队区域，挑一支喜欢的球队设为主队；最后去“我的”里写一写昵称和简介。几分钟下来，晓球就有了你的样子。

晓球的底部有五个入口，从左到右依次是首页、赛程、主队与关注、数据和我的。点击就能切换，在主内容区域左右滑动也可以翻页。大多数页面滑到顶部再往下一拉，就能刷新出最新的内容。

## 首页：一眼看见今天的球场

首页像一张每天更新的校园足球小报。最上面的轮播区展示当前赛事的海报和公告，往下是焦点赛事，最受关注的比赛会出现在这里，点一下就能进入详情，点“查看全部”就能看到完整赛程。官方公告条里放着赛事规则、时间安排等通知，想了解最新安排时来这里看一眼就好。

再往下是“绿茵动态”，这里是同学们分享照片、讲述比赛故事的地方。赛场上的一次精彩扑救、赛后队友们的合影、看台上的一声呐喊，都能在这里被看见。

首页顶部的搜索框可以帮你快速找到想看的内容。输入球队名、球员名或者一个关键词，结果会按球员、球队、比赛和动态分好类，点一下就能直达对应的页面。

## 赛程：每一场比赛都有自己的位置

在“赛程”页面，点击顶部的赛事名称，可以在不同赛事和赛季之间切换。日期条可以横向滑动，点某一天就只看当天的比赛，点“全部日期”则把整个赛季的安排一次铺开，下方列表按日期分组排好，每天有几场比赛也一目了然。

想找得更准一些，可以打开筛选器，按球队、比赛阶段、比赛状态来挑选，还能调整日期的排序方向。设好主队之后，勾上“只看我的主队”，主队的每一场比赛就都整整齐齐地排在眼前了。

每场比赛都带着清楚的状态标记，比如未开始、签到中、进行中、已结束和已确认，让你随时知道比赛走到了哪一步。到了淘汰赛阶段，点击“赛事进度”，还能看到每一轮已经完成了多少场，冠军之路走到了哪里。

## 比赛详情：把九十分钟装进口袋

点开任意一场比赛，最先映入眼帘的是比赛的头部信息：阶段与轮次、双方球队、比分、开赛时间和场地，有点球大战的比赛还会显示点球比分。点击球队就能走进它的档案。

详情页有三个标签。“比赛事件”按时间顺序记录进球、换人和红黄牌，部分事件还配有精彩片段，点开就能回看那一刻的画面。“首发阵容”展示双方的站位和替补名单，点击球员可以查看他的个人档案。“比赛评分”则在比赛结束后开放，你可以读一读比赛快报，看看大家给出的平均分，再给这场比赛打上一到五颗星，写下自己的赛后感想。一场比赛的余温，就在这些评分和评论里慢慢延续。

## 数据中心：用数字讲述赛季

“数据”页面是整个赛季的记分牌。在“积分”里可以看到小组积分表，场次、胜平负、净胜球和积分一列列排得清清楚楚；到了淘汰赛阶段，这里还会展开对阵图，谁和谁相遇、谁一路晋级，都看得明明白白。点击积分表中的任意一支球队，可以看到它更详细的统计，并一键进入球队档案。

“射手榜”和“助攻榜”记录着赛季里最耀眼的名字。点击榜单上的球员，就能看到他的完整档案和每一场比赛的表现。

## 主队与关注：把喜欢的放在手边

底部中间的入口是你的专属区域，它有时会以主队队徽的样子出现。在这里，你可以关注多支球队和多位球员，并选出一支作为自己的主队。主队会陪你出现在赛程筛选里，也会成为这个入口的主角。关注的球队和球员排在顶部，轻轻一点就能切换查看，喜欢的比赛和人随时都在手边。

如果你也想成为球队的一员，可以在球队档案里点击“申请加入”，选择想踢的位置，给队长留一段话，提交之后等待队长回复就好。

## 球队与球员：认识场上的每一个人

每支球队都有一份完整的档案，分为动态、赛程、球员、数据和资料五个部分。你可以读到球队的简介和口号，看看它这个赛季的全部比赛，翻一翻球员名单，也能看到与球队有关的动态。

每位球员同样有自己的档案。“赛程”记录着他踢过的每一场比赛，首发还是替补、出场了多少分钟都写在上面；“数据”汇总了出场、进球、助攻和红黄牌等统计，还有能力数据的展示；“资料”里写着位置、身高、惯用脚、年级和专业。认识一位球员，从这里开始就很自然。

除了球员档案，每位同学在社区里也有自己的用户主页，展示他发布的动态和个人资料。如果他同时是一名球员，主页上还会有通往球员档案的入口。

## 绿茵动态：每个人都是讲述者

在首页的发布入口，你可以写下一段五百字以内的文字，配上最多九张图片，再加上相关的球队、球员或者话题标签，一条动态就完成了。比赛日的心情、训练时的趣事、一张拍得刚刚好的照片，都值得被分享。

看到喜欢的动态，可以点个赞，可以收藏到“我的收藏”里慢慢回味，也可以转发到晓球动态，让更多人看到。在评论区里，你可以写下三百字以内的想法，附上表情和最多三张图片，还能直接回复某一位同学，让讨论一来一回地热闹起来。

写到一半临时有事也不用担心，晓球会在手机上替你留着草稿，回来之后可以接着写。

## 消息与私信：让交流更近一步

在“我的”里打开“我的消息”，所有和你有关的消息都集中在这里：一对一的私信会话、回复你的评论、提到你的内容、收到的点赞，以及申请和审核相关的系统通知。有新消息时会出现未读标记，点开就能查看，有关联内容的还可以一键跳转过去。

想和某位同学聊聊，可以在消息页点击“发私信”搜索对方，也可以在他的个人主页直接发起。会话中能看到消息是否已读，聊天的节奏自然又踏实。

## 我的：属于你自己的角落

“我的”页面收纳着和你有关的一切。在“个人信息”里，你可以修改昵称和个人简介，绑定或更换邮箱；点击头像，就能从相册里挑一张喜欢的照片作为新头像。

如果你是球员、队长、教练或者信息管理员，可以在“身份管理”里提交身份认证申请，写清楚申请说明，提交后在申请记录里随时查看进度。通过之后，还可以在“展示身份”里选择对外显示的身份标志，让大家一眼认出你在球场上的角色。已经关联了球员身份的同学，可以亲自编辑自己的球员资料，补充身高、位置、惯用脚、个人简介和技术自评，再换上一张精神的球员照片。

在“设置”里，你可以按自己的习惯调整使用体验，比如减少动画、增大动态文字、让比赛 GIF 自动播放，随时也能一键恢复默认。使用中有任何想法和建议，都可以通过“问题反馈”告诉我们，处理的进展会在反馈记录和系统消息里及时告诉你。

## 给队长和教练：把球队打理得井井有条

获得授权的队长和教练，可以在“我的”里进入“管理球队”。管理页分为球队主页、阵容和大名单三个部分，带队的日常工作都可以在这里完成。

在球队主页，你可以编辑球队的名称、简称、院系、成立年份、口号和简介，还可以为球队换上一张新的背景图。背景采用 2.8:1 的横向比例，拖动滑块就能调整取景，挑一张有气势的合影，球队主页立刻焕然一新。

在阵容页面，你可以新建多套阵容方案。先选好阵型，再点击球场上的每个位置挑选球员，排好之后保存，还可以把最满意的一套设为默认阵容。时间紧的时候，“按位置补全”会根据球员的位置帮你快速填好阵容，你只需要再微调一下。

在大名单页面，你可以为当前赛事编排报名名单：勾选球员、填好球衣号码、保存草稿，准备好之后提交审核。页面会清楚地显示名单状态、人数范围和截止时间，每一步都心中有数。同一页面下方还汇集了入队申请，新队员的加入请求在这里一键就能处理。

## 给信息管理员和管理人员

信息管理员可以在“我的身份”中打开自己的质量面板，查看记录质量分、当前状态、本轮的记录进度和近期的加减分原因，评分说明也写得清清楚楚，帮助大家把每一场比赛记录得更准确。

获得授权的组织管理员和平台管理员，可以在“身份管理”中处理同学们提交的反馈，查看相关内容并给出回复，让每一个问题都有回音。实名账号目录也在这里，方便管理人员进行身份核实。

## 写在最后

校园足球的魅力，在于它离我们很近。场上奔跑的是同窗，看台上喝彩的是室友，一场比赛的输赢，会成为好几天饭桌上的话题。晓球想做的，就是把这份热闹好好收藏起来，让每一个进球都有记录，每一支球队都有主页，每一个爱球的人都有地方说说心里话。

打开晓球，找到你的主队，下一个比赛日，我们球场边见。
